## 変更影響レビュー

- 公開 API / wire format / 永続化 / 設定 / observability への影響: `NodeConfig` の
  `trusted_cert_paths` を全ノードで設定し、server 側の client certificate
  verification を必須化した。QUIC wire format は変更しない。memory／health／cache
  API と Multi-Raft／TSO public mesh wiring を追加した。
- 既存テストで覆えない経路: 物理三 host、packet impairment、長時間 RSS／cgroup
  stability、外部 Prometheus scrape、旧版混在の実運用 rollout。
- 互換性・移行・rollback: mTLS 必須化は破壊的変更。全ノードの
  `trusted_cert_paths` を先に揃え、client certificate と key を配備してから
  切り替える。client certificate を提示しない旧版 node は handshake に失敗する。
  rollback は trusted paths と証明書を保持したまま全ノードを同一旧版へ戻す運用
  判断が必要であり、混在稼働を前提にしない。
- セキュリティ・性能・実ネットワークの確認: mTLS handshake rejection と local
  correctness を検証する。外部 security audit、性能 SLO、physical network の
  証明はこの版の主張に含めない。
