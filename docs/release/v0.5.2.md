## 変更影響レビュー

- 公開 API: FileTransfer の直接構築 API は検証可能。`MeshHandle` 統合 API は v0.6 に明示的に分離した。
- wire / persistence: compression、manifest、chunk retry、receiver finalization を integration test で確認した。
- 性能: 100 MB/s は固定した `ft-1g-v1` 二 container profile だけで判定する。物理二 host の `iperf3` と FileTransfer は配備診断であり、家庭内 LAN の帯域を release performance gate にしない。
- rollback: 公開前に物理 gate が失敗した場合はタグから publish へ進めない。
