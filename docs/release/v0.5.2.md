## 変更影響レビュー

- 公開 API: FileTransfer の直接構築 API は検証可能。`MeshHandle` 統合 API は v0.6 に明示的に分離した。
- wire / persistence: compression、manifest、chunk retry、receiver finalization を integration test で確認した。
- 性能: 100 MB/s は固定した `ft-1g-v1` 二 container profile だけで判定する。物理二 host の `iperf3` と FileTransfer は配備診断であり、家庭内 LAN の帯域を release performance gate にしない。#25 の phase evidence は原因帰属と local 回帰検知に使い、SLO の代替にはしない。
- メモリ安全性: WSLでも複数チャンネル反復転送のセッション解放とcgroup `memory.peak` / 作業後 `memory.current` を測定する。swap controllerの有無は環境適格性と分離し、実測メモリ安全性を無効化しない。
- rollback: 公開前に controlled profile、platform compatibility、または release environment gate が失敗した場合はタグから publish へ進めない。
