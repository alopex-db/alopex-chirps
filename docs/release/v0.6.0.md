## 変更影響レビュー

- 公開 API / wire format / 永続化 / 設定 / observability への影響: #17、#19–#24 の各 spec で実装開始前に記入する。
- 既存テストで覆えない経路: deterministic network、実ディスク crash/restart、TSO leader lease、public Mesh API、複合 QUIC traffic、public-registry dependency、versioned release gates。
- 互換性・移行・rollback: v0.5 RaftNode API の API signature compatibility を維持する。v0.5 / v0.6 混在 cluster は拒否する。破壊的変更と alopex-core version は migration / SemVer 根拠を残す。
- セキュリティ・性能・実ネットワークの確認: #19–#23 が roadmap の条件と evidence を定義し、#18 が対象版だけを release gate に結び付ける。
